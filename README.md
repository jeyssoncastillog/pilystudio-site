# PilyStudio

Sitio web oficial de PilyStudio — diseño de invitaciones digitales y portafolio de trabajos.

## Estructura

- `/inv/` — Invitaciones digitales (bodas y eventos)
- `/trabajos/` — Portafolio de trabajos
- `index.html` — Landing page principal

## Descripción

PilyStudio ofrece invitaciones digitales personalizadas y servicios de diseño para eventos especiales.
